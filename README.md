# ✝ Christian Birthday Blessing

A beautiful, single-file website that creates a personalized Christian birthday blessing with a Bible verse. Enter a name, click a button, and enjoy confetti, balloons, and a heartfelt message.

## ✨ Features

- Personalized "🎉 Happy Birthday, [Name]! 🎂" greeting
- 20 unique blessing messages and 8 closing prayers
- 130+ birthday-appropriate Bible verses (Old and New Testament)
- Verses focus on blessing, joy, love, hope, faith, wisdom, gratitude, protection, and God's promises
- No repeated verse until all verses have been shown in a session
- Animated confetti, floating balloons, and flickering candles
- Dark and light mode toggle
- Copy, Share, and Download buttons
- Works on phones, tablets, and computers

## 🚀 How to Open

### Option 1: Open on your computer

1. Download `index.html` from this repository.
   (Click the file, then click the **Download raw file** icon.)
2. Find the downloaded file on your computer.
3. Double-click it. It opens in your web browser (Chrome, Edge, Firefox, or Safari).

No installation or internet-based server is needed.

### Option 2: Open on your phone

1. Download `index.html` to your phone.
2. Open your **Files** app and tap the file.
3. Choose to open it with your browser.

### Option 3: Publish it online with GitHub Pages (free)

1. Go to your repository on GitHub.
2. Click **Settings** → **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Wait 1–2 minutes, then open:
   `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

Share that link with anyone.

## 🎂 How to Use

1. Type the birthday person's name in the text box.
2. Click **Generate Birthday Blessing**.
3. Enjoy the blessing and verse.
4. Use the buttons to **Copy**, **Share**, **Download**, or create a **New Blessing**.
5. Use the top-right button to switch between dark and light mode.

## 🛠 Built With

- HTML
- CSS
- JavaScript

Everything is in one file with no frameworks or dependencies. An internet connection is only used to load the Google Fonts.
